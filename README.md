# jamun-desktop-releases

Installers and the auto-update feed for the **Jamun desktop app**.

This repository holds build artifacts only — no source. Each release carries a Windows installer,
its `.blockmap`, and the `latest.yml` the app reads to check for updates.

**Install:** grab the `.exe` from [the latest release](../../releases/latest). The app updates
itself from then on.

> Builds are not yet code-signed, so Windows SmartScreen will warn on first install.
